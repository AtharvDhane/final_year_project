NATURAL LANGUAGE PROCESSING FOR SENTIMENT ANALYSIS IN
SOCIAL MEDIA: A TRANSFORMER-BASED APPROACH

ABSTRACT

Sentiment analysis of social media data has become increasingly important for
understanding public opinion, market trends, and crisis detection. This paper
proposes a BERT-based fine-tuned model for multi-class sentiment classification
(positive, negative, neutral, and mixed) on Twitter data. Using a dataset of
320,000 tweets spanning political discussions, product reviews, and COVID-19
discourse, the model achieves 93.4% accuracy — a 7.2% improvement over
traditional LSTM approaches. The study also introduces a novel aspect-based
sentiment extraction module that identifies specific topics driving sentiment.
Experiments are conducted in both English and Hindi to address multilingual
challenges in sentiment analysis.

1. INTRODUCTION

Social media platforms generate over 500 million posts per day, creating a
rich source of real-time public opinion data (Statista, 2023). Automated
sentiment analysis enables organizations, governments, and researchers to
derive actionable insights from this unstructured text at scale.

Traditional rule-based sentiment analysis systems suffer from poor performance
on informal language, sarcasm, and code-mixed text commonly found in social
media. The emergence of transformer-based language models, particularly BERT
(Devlin et al., 2019), has revolutionized NLP tasks.

1.1 Problem Statement

Existing sentiment analysis models fail to accurately classify nuanced
sentiments in multilingual, informal, and code-mixed social media content.
There is also a lack of aspect-level sentiment analysis that can identify
which specific aspects (price, quality, service) drive the overall sentiment.

1.2 Research Objectives

1. To fine-tune BERT for 4-class sentiment classification on social media data
2. To develop an aspect-based sentiment extraction module
3. To evaluate performance on both English and Hindi datasets
4. To compare transformer-based approaches with traditional ML and LSTM methods

2. RELATED WORK

Pang et al. (2002) pioneered ML-based sentiment analysis using Naive Bayes and
SVM on movie reviews, establishing baselines for the field.

Maas et al. (2011) introduced the IMDB dataset and demonstrated that
unsupervised feature learning improved sentiment classification accuracy.

Kim (2014) showed that CNNs applied to sentence-level classification outperform
traditional ML methods with simple pre-trained word vectors.

The introduction of BERT (Devlin et al., 2019) marked a paradigm shift, with
fine-tuned BERT outperforming all previous approaches on GLUE benchmark tasks.

2.1 Research Gap

Despite extensive work on English sentiment analysis, there is limited research
on:
- Multilingual sentiment analysis combining English + Hindi (Hinglish)
- 4-class classification including "mixed" sentiment
- Real-time social media datasets covering diverse topics post-2022
- Aspect-based sentiment at tweet level (not just document level)

3. METHODOLOGY

3.1 Dataset Collection

Data was collected via Twitter Academic API (2022-2024):
- Political tweets: 120,000 (India elections, US midterms)
- Product reviews: 80,000 (Amazon, Flipkart links shared on Twitter)
- COVID-19 discourse: 70,000
- General public sentiment: 50,000
- Total: 320,000 tweets (English: 210,000, Hindi: 110,000)

Labels: Positive (28%), Negative (35%), Neutral (26%), Mixed (11%)
Annotation: 3-annotator majority voting, Cohen's κ = 0.79

3.2 Preprocessing

- URL removal, @mention normalization
- Emoji conversion to text descriptors
- Code-mixed text detection using langdetect
- Tokenization using BERT WordPiece tokenizer (max_len=128)

3.3 Model Architecture

Base: bert-base-multilingual-cased (110M parameters)
Fine-tuning layers:
- [CLS] token representation → Dropout(0.3) → FC(256) → ReLU → FC(4) → Softmax

Aspect extraction:
- SpaCy NER for topic identification
- Custom rule-based aspect matcher
- Per-aspect sentiment scoring using attention weights

3.4 Training

- Optimizer: AdamW (lr=2e-5, weight_decay=0.01)
- Batch size: 16 (gradient accumulation: 4)
- Epochs: 4 (full fine-tuning)
- Warmup steps: 500
- Hardware: 2x NVIDIA A100 80GB
- Framework: HuggingFace Transformers 4.35

4. RESULTS

4.1 Overall Performance

| Model              | Accuracy | F1-Macro | Inference (ms) |
|-------------------|----------|----------|----------------|
| Naive Bayes       | 71.2%    | 68.4%    | 2ms            |
| SVM (TF-IDF)      | 76.8%    | 74.1%    | 5ms            |
| BiLSTM            | 86.2%    | 83.9%    | 18ms           |
| RoBERTa           | 91.7%    | 90.3%    | 45ms           |
| BERT-ml (ours)    | 93.4%    | 92.1%    | 48ms           |

4.2 Language-wise Performance

| Language | Accuracy | F1-Macro |
|----------|----------|----------|
| English  | 94.8%    | 93.6%    |
| Hindi    | 91.2%    | 89.7%    |

4.3 Class-wise F1

| Class    | F1-Score |
|----------|----------|
| Positive | 94.2%    |
| Negative | 93.8%    |
| Neutral  | 91.3%    |
| Mixed    | 89.1%    |

5. CONCLUSION

This research demonstrates that fine-tuned multilingual BERT significantly
outperforms traditional approaches for social media sentiment analysis.
The aspect-based module provides actionable insights beyond overall sentiment.
Future work will address sarcasm detection and real-time streaming analysis.
