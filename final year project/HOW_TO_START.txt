================================================================
COMMON PROBLEMS AUR UNKE SOLUTIONS
================================================================

  PROBLEM 1: "java is not recognized"
  ------------------------------------
    Java install nahi hai. Java 21 download karo:
    https://www.oracle.com/java/technologies/downloads/

  PROBLEM 2: "npm is not recognized"
  ------------------------------------
    Node.js install nahi hai. Download karo:
    https://nodejs.org/

  PROBLEM 3: "Port 8080 already in use"
  ------------------------------------
    PowerShell mein ye type karo:
    > netstat -ano | findstr :8080
    > taskkill /PID [woh_number] /F

  PROBLEM 4: "Port 27017 already in use"
  ------------------------------------
    MongoDB pehle se chal raha hai, koi problem nahi
    Ya phir:
    > net stop MongoDB
    Dobara start karo Step 2 se

  PROBLEM 5: "Connection refused" error frontend mein
  ------------------------------------
    Check karo ki backend aur MongoDB dono chal rahe hain
    Sahi order mein start karo:
    MongoDB -> Qdrant -> Backend -> Frontend

  PROBLEM 6: PowerShell Script nahi chali (start-backend.ps1)
  ------------------------------------
    PowerShell ko Administrator mode mein kholo aur ye type karo:
    > Set-ExecutionPolicy RemoteSigned
    Phir "Y" dabao aur Enter karo
    Ab dobara script chalao.
